# Java To-Do List

A simple command-line task-management application built while practising core Java and data structures.

## What I worked on

- Creating and managing tasks
- CRUD-style task operations
- ArrayList for in-memory task handling
- HashMap for key-based data handling
- Exception handling
- Object-Oriented Programming principles

## Tech Stack

- Java
- ArrayList
- HashMap
- OOP

## Project focus

This project helped me practise writing small Java applications, working with collections, handling input and exceptions, and keeping application logic organised.
